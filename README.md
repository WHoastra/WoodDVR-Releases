# WoodDVR downloads

Installer releases for **WoodDVR** (survey DVR, position fixes, video overlay, narration and broadcast for ROV and construction survey spreads) and the free **WoodDVR Reviewer** (playback and review of WoodDVR recordings). Both run on your own Windows 10 / 11 PC.

This repository holds the installers only; the source code is not public.

- Website, pricing and documentation: https://whoastra-labs-site.vercel.app/woodsolutions/wooddvr
- All downloads: https://github.com/WHoastra/WoodDVR-Releases/releases
  - `WoodDVR_Setup_<version>.exe`: the full application (speech model for offline narration transcription included)
  - `WoodDVR_Setup_<version>_3D.exe`: the same plus the COLMAP engine for the 3D Model add-on (NVIDIA GPU)
  - `WoodDVRReviewer_Setup_<version>.exe`: the free Reviewer, no licence key needed

Windows SmartScreen may show a notice on a new publisher's installer: choose *More info*, then *Run anyway*. All installers are built by Whoastra Labs LLC.
